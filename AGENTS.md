# AGENTS.md

Инструкции действуют для всего репозитория. Основной файл — [CLAUDE.md](CLAUDE.md): окружение, команды, инварианты, архитектурные правила и порядок работы. Карта кода — [PROJECT_MAP.md](PROJECT_MAP.md).

Кратко:

- Продукт: custom integration Home Assistant `hi_sosed`, случайная клеточная сетка коротких звуков по расписанию через `media_player.play_media`.
- Источник истины: [docs/PRODUCT_REQUIREMENTS.md](docs/PRODUCT_REQUIREMENTS.md) и [docs/adr/](docs/adr/). Если код и спецификация расходятся, решение фиксируется в ADR до изменения поведения.
- Local-first, без скрытых сетевых вызовов. Вне окна, после `stop`, удаления и выгрузки звук не играет. Каждый callback проверяет `generation`.
- Домен (`models.py`, `engine.py`) без I/O. Мутации только через `ScenarioManager` под одним lock, без await внешних операций внутри lock.
- В логах нет имён, путей и URI пользователя.
- Не заявляй о проверках, которые не запускались. Указывай точные команды и непроверенные платформы.
