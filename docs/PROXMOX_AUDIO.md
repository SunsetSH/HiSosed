# Звук для HiSosed, когда Home Assistant работает в Proxmox

HiSosed играет только через сущности `media_player` (ADR-0001, ADR-0002). Home Assistant OS в виртуальной машине Proxmox не видит ни звуковую карту, ни Bluetooth сервера. Поэтому звуком занимается отдельный маленький **аудиоузел**: контейнер или ВМ с MPD и PipeWire. Home Assistant управляет им как обычными плеерами MPD. Решение описано в [ADR-0004](adr/0004-audio-node-onboarding.md).

> Не добавляйте **Audio Device** в настройках ВМ Home Assistant и не ставьте ради этого дополнение **VLC**. Audio Device — это виртуальная звуковая карта: SPICE отправляет звук в окно просмотра, Dummy его выбрасывает. К гнезду сервера она не ведёт. VLC играет через ту же ВМ, которая встроенную карту не видит.

## Быстрый путь: всё из панели HiSosed

1. HiSosed → **Колонки** → «Подключить колонку к серверу». Выберите, как подключена колонка: **проводом** (гнездо 3.5 мм сервера или USB-звуковая карта, воткнутая в сервер) или **по Bluetooth**. Выберите, сколько звуков должно звучать одновременно.
2. Скопируйте команду. Откройте веб-интерфейс Proxmox → слева сервер (обычно `pve`) → **Shell**, вставьте команду и нажмите Enter.

   ```sh
   # провод
   wget -qO- https://raw.githubusercontent.com/SunsetSH/HiSosed/main/scripts/proxmox/host-setup.sh | sh -s -- --mode jack --players 2
   # Bluetooth
   wget -qO- https://raw.githubusercontent.com/SunsetSH/HiSosed/main/scripts/proxmox/host-setup.sh | sh -s -- --mode bluetooth --players 2
   ```

3. Дождитесь баннера «Готово. Адрес аудиоузла: 192.168.x.x». Для Bluetooth скрипт до этого попросит перевести колонку в режим сопряжения и выбрать её номер из списка.
4. Впишите адрес в панели и нажмите **«Подключить»**. HiSosed сам добавит плееры MPD («HiSosed 1», «HiSosed 2»…) и задаст им тип колонки.
5. У новой колонки нажмите **«Проверить звук»**.

Если панель предупреждает, что Home Assistant не знает свой адрес, укажите его: Настройки → Система → Сеть → «Локальная сеть» (например, `http://192.168.1.10:8123`). Плеер MPD скачивает звуки по этому адресу.

### Что делает команда

| | Провод (`--mode jack`) | Bluetooth (`--mode bluetooth`) |
|---|---|---|
| Что создаётся | привилегированный LXC `hisosed-audio`, Debian 12, 1 ядро, 512 МБ, 4 ГБ | ВМ `hisosed-bt` из cloud-образа Debian 12, 1 ядро, 512 МБ, 6 ГБ |
| Что отдаётся | все звуковые карты хоста (`/dev/snd`) | USB Bluetooth-адаптер хоста (находится автоматически, или `--usb VID:PID`) |
| Время | 2–5 минут | 5–10 минут + сопряжение |
| Автозапуск | `onboot=1` | `onboot=1` |

Внутри узла `audio-node.sh`:

- ставит MPD и PipeWire и запускает N плееров на портах `6600…`, а PipeWire смешивает их звук;
- для провода снимает mute с карты при каждой загрузке и выбирает аналоговый выход вместо HDMI;
- для Bluetooth ставит прошивки адаптеров Intel и Realtek и раз в 30 секунд переподключает колонку.

Почему контейнер привилегированный: в обычном (unprivileged) LXC звуковые устройства видны, но открыть их нельзя. Почему для Bluetooth нужна ВМ: Bluetooth-сокеты ядра не работают в отдельном сетевом пространстве контейнера.

### Параметры

```text
--mode jack|bluetooth   тип узла (обязательно)
--players 1-4           сколько плееров (сколько звуков одновременно), по умолчанию 2
--id N                  номер контейнера/ВМ (по умолчанию следующий свободный)
--storage NAME          хранилище диска (по умолчанию первое подходящее)
--bridge vmbr0          сетевой мост; адрес выдаётся по DHCP
--usb VID:PID           какой Bluetooth-адаптер отдать ВМ
--pair                  заново выполнить сопряжение Bluetooth-колонки
--check                 показать, что видит узел, и проиграть тестовую фразу
```

Повторный запуск находит уже созданный узел и только переустанавливает его. Так же меняется число плееров: запустите команду с новым `--players` и снова нажмите «Подключить».

## Если что-то не так

- **Звука нет, проверка в HiSosed проходит.**
  - Кабель должен идти из зелёного гнезда на задней стенке (линейный выход) в линейный вход усилителя (AUX, CD). На усилителе нужно выбрать этот вход.
  - Затем запустите в Proxmox ту же команду с `--check`. Она покажет карты и выходы (выход HiSosed отмечен `*`) и произнесёт «Front center».
- **«the host has no playback device in /dev/snd».** Хост не видит звуковую карту. Чаще всего встроенный звук проброшен в какую-то ВМ через PCI (Hardware → PCI Device): уберите этот проброс. Ещё бывает, что звук выключен в BIOS.
- **«no Bluetooth adapter found».** Воткните USB Bluetooth-адаптер в сервер или укажите `--usb VID:PID` (посмотреть: `lsusb`). Встроенный в материнскую плату адаптер обычно тоже USB-устройство, и скрипт его найдёт.
- **Колонка Bluetooth не подключается.** Переведите её в режим сопряжения и запустите команду с `--pair`. У колонки в HiSosed нажмите «Подобрать настройки».
- **«Подключить» пишет «не отвечает».** Проверьте адрес и что команда закончилась баннером «Готово». Ещё раз: `--check`.
- **Добавить плеер вручную.** Настройки → Устройства и службы → Добавить интеграцию → Music Player Daemon (MPD). Хост — адрес узла, порт 6600, 6601…, пароль пустой.

## Ручная установка

Если узел нужен на другой машине (Raspberry Pi, отдельный компьютер с Debian), выполните там от root:

```sh
wget -qO- https://raw.githubusercontent.com/SunsetSH/HiSosed/main/scripts/proxmox/audio-node.sh | sh -s -- --mode jack --players 2
# или --mode bluetooth, затем: hisosed-bt-pair
```

Адрес машины впишите в HiSosed → Колонки → «Подключить».

## Почему обрезается начало звука по Bluetooth

A2DP-колонки засыпают и открывают поток с задержкой 0,2–2 с. Против этого в профиле колонки HiSosed есть настройки, и «Подключить» для Bluetooth включает их сразу:

- **прогрев**: за N секунд до окна `turn_on` и тихий клип;
- **не давать уснуть**: тихий клип, если колонка молчит дольше N секунд, только внутри идущего окна;
- **компенсация задержки**: команда уходит раньше, но никогда не раньше начала окна.
